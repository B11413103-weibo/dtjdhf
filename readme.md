# 盆栽照明與缺水警報系統 (NUCLEO-G474RE 期中專題)

智慧盆栽保姆：自動排程扣水、缺水時紅燈狂閃警報，並支援終端機遠端查看狀態與調整生長補光燈亮度。

## 1. 情境故事
家裡種了些植物，但總是忘記澆水、澆太多水，或是室內採光不足，導致植物一株株枯萎。這個裝置能模擬植物水分流失，並在極度缺水時發出急促的視覺警報，同時允許使用者遠端遙控生長燈與補水，成為植物殺手的救星。

## 2. 替身對照 (故事裡的模組 → 板上替身)
- **土壤極度乾燥 (0%)** → 藍色按鍵 (B1 / PC13) 按下模擬。
- **缺水警報器** → 板載 LED (LD2 / PA5) 10Hz 快速閃爍。
- **生長補光燈** → TIM3_CH1 (PWM) 外接 LED，控制亮度。
- **目前水量指示** → TIM3_CH2 (PWM) 外接 LED，亮度代表水量多寡。
- **雲端監控中心** → 電腦終端機 (SerialAssistant / Python)，透過 UART 連線。

## 3. 功能與驗收條件
- **自動扣水**：開機水量 100%，每 2 秒自動扣 1%。實測：終端機數值與指示燈亮度皆緩慢下降 (通過)。
- **缺水警報**：當水量 < 20% (或按下 B1 強制歸零) 時，PA5 紅燈以 10Hz 狂閃。實測：視覺閃爍明顯，終端機顯示「缺水救援」 (通過)。
- **指令調光**：輸入 `light 80`。預期：TIM3_CH1 補光燈亮度變為 80%。實測：亮度即時改變 (通過)。
- **指令澆水**：輸入 `water 100`。預期：水量恢復 100%，警報燈關閉。實測：PA5 熄滅，TIM3_CH2 恢復最亮 (通過)。

## 4. 用到的技術 (第 3~7 週技術勾選表)
- [x] **GPIO 輸出**：PA5 缺水警報紅燈 | MODER = 01、BSRR 設/清
- [x] **GPIO 輸入**：PC13 按鍵模擬缺水 (B1) | MODER = 00、EXTI 的來源腳
- [x] **複用功能 AF**：PA2/PA3 遠端終端機連線 | USART2 收發、MODER = 10、AFR 選 AF7
- [x] **PLL 170 MHz**：計日與鮑率的共同基準 | HSI16 ÷4 ×85 ÷2、FLASH 4 等待週期
- [x] **外部中斷 EXTI**：B1 按下切換缺水/補滿狀態 | EXTICR4 選 PC13、RTSR1/FTSR1 (Rising edge)、PR1 寫 1 清
- [x] **NVIC 致能**：TIM2、EXTI15_10、USART2 三支 ISR 都能進來 | ISER 啟用
- [ ] 優先權與巢狀：(無使用)
- [x] **軟體去彈跳**：B1 按一下只算一次切換 | 時間戳 ticks - t_btn ≥ 50 ms 才算
- [x] **UART 傳送**：上雲端，每秒定時 report() 狀態一行 | USART2 115200 8N1、BRR = 1476、輪詢 TXE (主迴圈執行避免卡死)
- [x] **UART 接收+環形緩衝**：接收 light/water 指令 | RXNE 中斷入列、主迴圈出列、遇換行才解析
- [x] **Timer 定時中斷**：1ms 排程扣水與紅燈 10Hz 閃爍計時 | TIM2 PSC = 169、ARR = 999
- [x] **PWM**：TIM3 CH1/CH2 控制補光燈與水量燈亮度 0~100% | CCMR1、CCR1/CCR2 控制工作週期
- [ ] 輸入捕捉：(無使用)

## 5. 腳位表
- **PC13 (B1)**：USER BUTTON，EXTI 輸入 (無 Pull-up/Pull-down，Rising edge 觸發)。
- **PA5 (LD2)**：GPIO Output，預設 Low，做為缺水警報燈。
- **PA2 / PA3**：USART2 TX / RX，連接 ST-LINK 虛擬通訊埠。
- **TIM3_CH1 (依 CubeMX 綠色腳位)**：PWM 輸出，外接生長補光 LED (串接限流電阻至 GND)。
- **TIM3_CH2 (依 CubeMX 綠色腳位)**：PWM 輸出，外接水量指示 LED (串接限流電阻至 GND)。

## 6. 建置與執行
1. 使用 STM32CubeIDE 開啟專案，點擊 `Project > Build Project`。
2. 點擊 `Run` 將程式燒錄至 NUCLEO-G474RE。
3. 開啟 SerialAssistant 或執行 `app.py`，設定 Baud Rate `115200`, `8N1`。
4. 終端機指令用法 (請附加換行符號 `\n` 或 `LF`)：
   - 輸入 `light [0-100]` 控制補光燈亮度。
   - 輸入 `water [0-100]` 補充電子盆栽水量。

## 7. 程式結構
- **ISR (中斷服務常式)**：
  - `TIM2_IRQ`：提供 1ms 系統滴答，負責計算 2 秒扣水、控制 10Hz 警報燈翻轉，並每秒設定 `uart_tx_flag = 1`。
  - `EXTI15_10_IRQ`：偵測 B1 按下，執行 50ms 去彈跳後切換缺水/滿水狀態，並即時更新 PWM。
  - `USART2_IRQ`：純粹將收到的 byte 放入 Ring Buffer (環形緩衝區)，立即結束。
- **Main Loop (主迴圈)**：
  - 輪詢 `uart_tx_flag`，若為 1 則執行非阻塞的字串發送 (`HAL_UART_Transmit`)。
  - 從 Ring Buffer 取出資料 (`RingPop`)，遇到換行字元 `\n` 時，使用 `sscanf` 解析 `light` 與 `water` 指令並更新 TIM3 的 CCR 值。

## 9. AI 使用說明
- **使用範圍**：在實作 UART 接收與指令處理時，遇到中斷卡死 (Deadlock) 問題，使用 Gemini 協助除錯。
- **查核方式**：AI 建議引入 `uart_tx_flag` 將耗時的 `HAL_UART_Transmit` 移出 1ms 中斷，改由主迴圈執行。我將程式碼套用至 `main.c` 並燒錄測試，確認終端機回報正常且按鍵不再卡死，驗證了非阻塞架構的必要性。

## 10. 已知限制
- 目前使用按鍵瞬間切換 0% 與 100% 來模擬土壤極端狀態。未來若要連接真實的土壤濕度感測器，需將 PC13 替換為 ADC 輸入腳位，並在迴圈或定時器中定期讀取類比電壓值來轉換為 0~100% 的水量。
